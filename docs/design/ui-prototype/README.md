## 打开原型

在仓库根目录执行 `python3 docs/design/ui-prototype/preview.py`，然后打开
**http://127.0.0.1:8765/**。退出对应终端进程即可停止服务。
端口占用时可传 `--port 8766`，地址相应改为该端口。

也可直接打开本目录 [index.html](index.html)；需保留仓库相对目录结构。
直接 `file://` 打开时，浏览器可能限制剪贴板，因此推荐本地预览服务。

- 无需安装 npm 包、API key 或构建 App。
- `preview.py` 仅监听 `127.0.0.1`，白名单提供 HTML/CSS/JS 及仓库现有的 markdown-it、highlight.js。
- 不提供目录列表或任意文件访问；CSP 禁止页面发起连接，所有图标为内嵌 SVG，无 CDN/远程字体。
- 草稿、模型选择、审批与演示消息只存内存。切换场景保留各场景状态；刷新页面全部清空。
- 「重置场景」清除当前场景的演示操作和草稿，取消其模拟任务，其他场景不受影响。

## 比较方案

| | A · 文档工作台（推荐方向） | B · 轻量聊天 |
|---|---|---|
| 回答 | 无大面积背景卡片，文档式阅读 | 中性白色/深色卡片，明确消息边界 |
| 用户输入 | 与正文阅读列对齐的轻量区域 | 右对齐浅底气泡 |
| 执行过程 | 紧凑分隔行，按需展开 | 轻量折叠卡 |
| 更适合 | 长回答、代码与连续阅读 | 偏好对话感、明确消息归属的用户 |

A/B 仅改变展示样式，不创建两套会话数据；切换不会重建消息 DOM 或清除输入、展开状态。
两种布局的高度可能不同，**不承诺 A/B 切换后同一行保持同一个屏幕位置**；此切换只用于设计比较，不是生产交互。
所有场景、指标、模型与模拟响应两边一致，避免拿不同内容比较观感。

## 已实现的演示交互

1. **完成 · 长回答**：Markdown、代码复制、表格、过程展开、用量弹窗与示意差异。
2. **执行中**：主动作变为停止；停止保留下一条草稿，不把未完成步骤写成成功。
3. **等待审批**：操作目标、风险与授权范围明确；支持查看差异、允许一次和拒绝，均不执行真实操作。
4. **多模型协作**：独立工作目录、角色署名、阶段提示，以及手动追加评审员演示发言。
5. **连接失败**：草稿保留，模拟重试中/恢复状态；切换回来不会重新出现已恢复的错误。
6. **新会话**：当前项目已经选择；建议按钮仅填草稿，不自动发送；发送后退出欢迎态。

共用控件：深色/浅色/跟随系统、800px 窄窗口、侧边栏收起、演示附件添加/移除、回到最新。
小于 700px 的浏览器视口隐藏侧边栏，仍可从原型上方切换场景；这只是审阅时的降级布局，不是新的移动端产品。

键盘规则：
- 输入框中 Return 或 ⌘/Ctrl + Return 发送演示消息，Shift + Return 换行。
- IME 组词确认不发送。运行中 Return 不停止、不发送；用 Shift + Return 换行。
- 模拟生成约 2.2 秒，可明确点击停止；后台场景完成不会覆写当前场景。
- Esc 关闭弹窗并恢复焦点；按钮支持键盘焦点样式。
- 复制会写系统剪贴板，其他演示操作不写外部状态。

## 设计规范

| 层级 | 原型规则 |
|---|---|
| 色彩 | 暖中性背景、单一低饱和绿色强调；警告与错误有文字和图标，不只靠颜色 |
| 正文 | 系统字体 14px、1.85 行高；正文列最多 800px（含内边距），代码 12px/1.75 |
| 标题 | 文档主标题 20px，窗口标题 14px；靠字号、字重、间距区分，不靠彩色底板 |
| 间距 | 以 4/8px 为基础，内容块使用 16/24/32px 附近的间距；长文与输入区对齐 |
| 圆角 | 小控件 6–8px，输入面板 11px，窗口 14px；不把所有元素都做成胶囊 |
| 输入区 | 一个完整面板；焦点时强调，模型与附件属于次级操作，发送/停止占据同一固定位置 |
| 状态 | 默认只展示主要任务状态，用量按需查看；运行、停止、审批、错误语义分开 |
| 动效 | 不使用礼花或持续文字闪烁；只保留轻量状态指示，支持 reduced motion |

原型字号为浏览器 CSS 像素，不是已定稿的 AppKit pt；生产版仍需在 macOS 15/26、不同缩放与真实字体下验收。
颜色变量集中在 [prototype.css](prototype.css)，不能把原型 CSS 全量覆盖到生产渲染器。

重新运行浏览器检查时，先在 Ego 建立并打开该原型的 TaskSpace，然后在仓库根目录运行
`{ printf 'globalThis.NEWPI_UI_SPACE = 1;\n'; cat docs/design/ui-prototype/checks.mjs; } | ego-browser nodejs`，
把 `1` 替换为**实际已有的** TaskSpace 编号。脚本使用 `p1`，不自动创建或关闭浏览器空间。
